## 📝 Description

The Mental Health Calculator is an intuitive Python-based tool designed to help individuals monitor their emotional wellbeing through standardized psychological assessments. By leveraging the Depression, Anxiety, and Stress Scale (DASS) methodologies, the application offers both the streamlined DASS-21 and the comprehensive DASS-42 versions. Users are guided through a series of self-report questions, after which the program calculates and categorizes their responses to provide clear insights into their current levels of stress, anxiety, and depression. This project serves as an accessible resource for private self-assessment using clinically recognized metrics.
